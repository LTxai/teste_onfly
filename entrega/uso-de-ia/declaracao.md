# Declaração do uso de Inteligência Artificial

## Ferramenta utilizada:

- GitHub Copilot integrado ao VS Code;

## Participação da IA:

- Análise dos arquivos de teste;
- Indentificação de arquivos em desacordo com a regra de negócio;
- Explicação de causa-raiz de eventuais problemas;
- Sugestão de correções;
- Criação de testes adicionais;

## Participação do desenvolvedor:

- Criação de prompt direcionando para a análise dos testes;
- Avaliação das sugestões de correções melhoradas;
- Aplicação das correções;
- Execução dos testes automatizados;
- Validação de resultados;
- Criação de prompt para gerar testes adicionais;
- Revisão do código gerado pela inteligência artificial;
